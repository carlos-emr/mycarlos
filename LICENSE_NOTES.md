# License declarations preserved during import

The initial commit of `carlos-emr/mycarlos` included an AGPL-3.0 license text in [LICENSE](LICENSE).
That file is preserved unchanged.

The imported application declares `GPL-2.0-or-later` in `src-tauri/Cargo.toml` and was developed in
the CARLOS repository. Its existing declaration and source notices are preserved. The original
GPL version 2 text is included in [COPYING.md](COPYING.md), and the source repository's project-wide
notice is retained in [UPSTREAM_NOTICE.md](UPSTREAM_NOTICE.md). That notice describes the upstream
repository as a whole, rather than attributing every listed contribution to this application.

The repository move does not relicense the imported application under the destination's AGPL
license. Maintainers must resolve and document the intended project-wide licensing before a
supported release. Dependency licenses remain recorded in their packages and generated SBOMs.

See [HANDOFF.md](HANDOFF.md) for the source revision and original contribution history.
