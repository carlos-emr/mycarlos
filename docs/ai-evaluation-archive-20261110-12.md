# AI summary evaluation experiments, 10–12 Nov 2026 (archive)

This branch keeps every commit of the local AI-summary evaluation work from 10–12 Nov 2026, so the local copies could be removed. **Do not merge.** The last commit is an archive merge: it lists every experiment branch as a parent but keeps main's files unchanged, so this file is the only change against main.

- Every run used FAKE documents only.
- Each experiment is one change to the summary's instructions, usually stacked on another one ("K12, on K11" = K12 is K11 plus one change).
- The experiments are alternative versions of the same prompt, so they cannot be combined into one working change.
- Results (graded rows, ladder screens, reviews) are kept in the private evaluation records, not here. No experiment in this archive was adopted; the current candidate is #313.
- The frozen scorer used for grading is `scripts/summary-evaluation/harness/compare.py` on the `agent2/rule9-20261111` tip below (sha256 starts `bc3b898f`).
