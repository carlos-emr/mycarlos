# Security reporting

myCarlos is an unreleased synthetic-data evaluation. No version is approved for patient records.

Do not report a suspected vulnerability or patient-data incident in a public issue. During this
repository handoff, use the existing
[CARLOS private advisory channel](https://github.com/carlos-emr/carlos/security/advisories/new)
and identify `carlos-emr/mycarlos` and the affected source revision. Include a minimal synthetic
reproduction, with no patient files, vaults, passwords, exports, screenshots, or sensitive logs.

The upstream policy's targets remain acknowledgement within five business days and initial
assessment within ten business days. These are volunteer-maintainer targets, not guarantees.

Dedicated private vulnerability reporting is not enabled in this repository at import time.
Repository administrators must enable and verify it before replacing the existing intake route.
Production incident ownership, remediation deadlines, and privacy/clinical contacts remain
release gates in [SECURITY_OPERATIONS.md](SECURITY_OPERATIONS.md).
