# Helper affinity tiny-control source

This unrun adapter prepares five bounded controls: positive helper affinity 1234 and124, plus rejection of the wrong interpreter ELF hash, fixture argv with two threads, and a second helper. It uses the exact V13 observer, affinity function and task observer with an authenticated Python interpreter ELF fixture. Original full fixture argv is preserved. The production native argv callback, full model phase and model execution are explicitly outside this qualification scope.

The harness starts on 1234 at nice10. Each positive case changes its single helper at the authenticated kernel EXEC stop, before the interpreter's first instruction, then checks its three held worker tasks and the harness task samples. Both masks use the same setter once. Observing controllers run on CPU0 at nice19. Children are created before their parents lower priority; no priority increase is needed.

Expected refusal kills only the bound rejected helper while its harness remains the actual parent and reaps all child statuses. The second-helper control also releases the accepted helper normally. The adapter requires normal harness completion and owned cleanup; unknown terminal waits are never waived.

All five cases share the original 30-second bound and six-second outer cleanup reserve. All child commands use isolated Python with bytecode disabled. The outer requires a direct Root parent, unchanged PTY and independently observed completion before its qualification candidate can be accepted.

Static source review, source hashes and AST checks passed after isolated-launch and ordered-cleanup fixes. No live controls, native compilation or model run were performed for this adapter. The controller's 214 pure mocks are separate evidence and do not establish adapter success.

This public snapshot contains only source and source hashes. It excludes the private local binding, runtime grants, input data, actual receipts and Root authority. A new reviewed local binding, finite serial launch admission and independent actual evidence are required before execution or qualification. This backup does not authorize a launch.
