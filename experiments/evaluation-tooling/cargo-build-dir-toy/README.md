# Cargo 1.98 split build-directory source experiment

This dependency-free toy checks whether shared intermediate artifacts can coexist with separate final binary directories and retained older executable copies. Two workspace paths use the same package/version/target names, identical integration harnesses, and different library markers. The harness embeds `env!("CARGO_BIN_EXE_split-helper")` and prints its actual binding before checking runtime expectations.

The runner first builds A, copies its harness by bytes, and snapshots A's final helper and independent harness copy. B has older changed-source mtimes and an unchanged harness. Its ordinary build records Cargo freshness, the helper output and the actual embedded path; a failed binding assertion is diagnostic evidence. A subsequent phase touches only B's disposable `src/lib.rs`, `src/main.rs`, `tests/contract.rs` and `build.rs` mtimes, repeats the same full recipe, and requires library/helper/harness `fresh:false`, the new final path and B's marker. It checks old A bytes/device/inode/mode, records hardlink counts and cache aliases, and runs A again without Cargo repair. A shared harness path/inode is not an immutable copy: rebuilt bytes may replace it in place.

Only disposable runtime copies receive mtime changes. The source manifest covers this portable source snapshot, not any earlier local invocation. No execution result or grant is included. This source experiment does not qualify application caches, native/model binaries, clinical output, speed or adoption. Source review and syntax checks are separate from a fresh execution and independent cleanup/hash acceptance.

A separately issued scheduling grant is required before executing `bash run-after-grant.sh FRESH_SCRATCH_DIR CARGO198_TOOLCHAIN_BIN`. Use an absent scratch directory outside this source tree and an explicit Cargo1.98 toolchain bin directory. The runner requires CPU0/nice19, one Cargo job, offline/locked builds, no dependencies or compiler wrapper, an internal13-second work deadline and outer TERM14s/KILL1s bound. It refuses retries in the same scratch directory and preserves the first result and logs. No installed application/cache path is supplied or accessed by the toy.

Official source references are pinned to installed Cargo commit `797e8a9bc`: [configuration](https://github.com/rust-lang/cargo/blob/797e8a9bc/src/doc/src/reference/config.md) and [build cache](https://github.com/rust-lang/cargo/blob/797e8a9bc/src/doc/src/reference/build-cache.md). `build.build-dir` / `CARGO_BUILD_BUILD_DIR` selects intermediates; target-dir selects final artifacts. Intermediate paths are discovered from Cargo JSON. Separate paths alone do not establish freshness or old binary retention.
