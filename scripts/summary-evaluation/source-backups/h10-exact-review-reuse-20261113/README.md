# Unportable H10 review-reuse source backup

This directory preserves two exact Python source files from a private evaluation environment. The `.py.source` suffix marks archival source and avoids automatic test discovery. This draft backup does not install an evaluation tool or modify the app.

The helper is designed to copy only byte-exact independently reviewed statement evidence after the operator independently admits a complete run. It requires fixed external source/data paths and pinned hashes that are intentionally absent here. The negative controls also depend on those private inputs; these files are not portable or runnable from this checkout alone.

No review CSV, review key, clinical document, raw model output, runtime grant, completion proof, scorer report, result artifact, credential, or private handoff file is included. Source strings referencing environment-specific paths and hashes are retained to preserve the reviewed code exactly; those references are not the underlying evidence.

The helper does not run inference or the scorer, validate native/process/guardian cleanup, establish runtime acceptance, or authorize another evaluation stage. Original scoring criteria, tags, corpus freezes and review artifacts are unchanged. Existing H10 reject-only semantics and the original raw UNFROZEN result remain.

The source was peer reviewed after explicit document-event/page-hash and duplicate-score-label guards were added. Fourteen lightweight controls passed in the original private environment. No application build, model run, database action, current-run scoring or grade transfer was performed for this source backup.
