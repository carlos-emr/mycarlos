# V13 metadata issuance source archive

This archive preserves the reviewed, fixed-purpose Root metadata issuance source
and its command template as inert `.source` files. It is outside the application
and test paths. The files retain environment-specific absolute paths, proof hashes,
and dependencies on private reviewed helpers; they are unportable archival source.

The script checks a completed-run proof, accepted function qualification, retained
owner window, source and executable identities, and the full four-phase budget.
It prepares metadata and command strings without launching those commands. Root
must independently verify each actual phase before delivering the next command.

The final source passed AST validation and a source peer with no outstanding
findings; the command template passed `bash -n`. These are source checks, not a
claim that the archive qualifies any runtime, model, clinical result or adoption.

Only these source copies and this README are backed up. No grants, qualification
JSON, runtime records, review sheets or keys, clinical documents, model weights,
scores, private handoff files, or credentials are included.
